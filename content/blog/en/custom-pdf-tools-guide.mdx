QuickShed includes five PDF tools. They cover common page and text tasks without requiring a separate desktop editor.

## Choose the right PDF tool

- `PDF Merger` combines two or more selected PDF files into one document.
- `PDF Page Remover` removes selected pages and exports a new PDF.
- `PDF Rotate` rotates PDF pages to a selected angle.
- `PDF Watermark` adds text to each page with controls for size, opacity, rotation, and color.
- `PDF to Text` extracts text by page and lets you copy all extracted text.

The tools handle selected files in the browser. They do not upload those files through the tool code in the current catalog. The browser still controls available memory and file size, and a malformed or unsupported PDF can fail to process.

## Merge PDF files

1. Open `PDF Merger` from the PDF Tools category.
2. Select two or more PDF files with `Add PDF Files`.
3. Review the file order. Remove a file if you added the wrong one.
4. Choose `Merge PDFs`.
5. When the result is ready, choose `Download Merged PDF`.

The merger keeps the pages from each selected file in the order shown on the page.

## Remove pages

Open `PDF Page Remover`, select a PDF, and choose the pages to remove. The tool prevents an export that would remove every page. Choose `Remove Selected Pages`, then download the new file.

## Rotate or watermark pages

`PDF Rotate` applies the selected angle to the pages in the file. `PDF Watermark` places the text you enter on each page and lets you adjust its appearance before downloading the result. These tools create a new browser download; they do not edit the original file on disk.

## Extract text

`PDF to Text` reads the text layer page by page. Choose a page tab to inspect one page or use `Copy All` for the complete extracted text. Scanned pages without a usable text layer may produce little or no text because this tool does not perform optical character recognition.

## What "local" means here

The PDF tools use browser file handling and PDF-processing code. Selected file data is read into the page so the result can be created, then the result is offered as a browser download. This is a processing description, not a promise that browser memory is unlimited or that the site can always be opened offline.

QuickShed does not add product analytics or tracking scripts to these tool flows. For the broader storage and data-flow policy, read the privacy policy and the badge shown on each tool page.
