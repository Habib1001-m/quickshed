QuickShed is a collection of 90 browser-based tools for calculations, text, PDFs, images, developer tasks, and everyday utilities. You can use the English or Arabic interface, search by name or category, and save selected preferences in this browser.

## Use the tool badge

Each tool page shows a data-handling badge. Read it before entering sensitive information.

- `Local`: the tool processes its input in the browser and does not persist it through the tool.
- `File-only`: the tool works with the file you select in the browser and does not persist it through the tool.
- `On-device`: the tool can save selected data in browser storage so it is available in this browser later.
- `API`: the tool uses an external service. The page should disclose that transfer before it occurs.

The badge describes the tool's data flow. It does not promise that the whole website is available without a connection.

## Start with search or categories

Use the search field to find a tool by name, category, or keyword. The Categories page groups the catalog into 11 areas, including calculators, text tools, converters, PDF tools, developer tools, and security tools. Favorites and other saved preferences stay in this browser and can be cleared from Settings.

## Browser processing and offline access

QuickShed can cache selected static assets through its service worker. Navigation is treated separately, so cached assets are not a guarantee of offline site access. A local tool may process an input without sending it to a service once its page and code are available, but browser storage, memory, and file-size limits still apply.

## English and Arabic interfaces

Switch languages from Settings. The interface changes its language and text direction together, so English uses left-to-right layout and Arabic uses right-to-left layout. Tool names, descriptions, and instructions are maintained in both languages.

QuickShed is free to use and does not require an account or show ads. For the exact handling of a particular input, use that tool's badge and the privacy policy.
