# v0.6.0 launch plan (historical)

**Status:** Historical record. This plan is not a deployment instruction.

The original v0.6.0 plan grouped work into product polish, privacy and security, content, release verification, and public documentation. It also identified the need to keep the English and Arabic experiences aligned and to validate the application in desktop and mobile Chromium.

The plan is retained to explain the shape of the v0.6.0 work. Current behavior comes from the source tree and current release checks. Use [`CONTRIBUTING.md`](../../CONTRIBUTING.md) for development and pull-request guidance, and run `npm run release:check` for the aggregate validation gate.

A successful local gate is evidence about the checked revision. It is not publication or deployment approval.
