# v0.6.0 release checklist (historical)

**Status:** Historical record. This checklist is not the current release control.

This file records the early v0.6.0 release checklist and its intended work areas: application behavior, security, public assets, documentation, dependency review, and browser checks.

The active release procedure is maintained in [`CONTRIBUTING.md`](../../CONTRIBUTING.md) and the repository's `release:check` script. Run that command against the revision under review instead of treating the historical checkboxes in this file as current status.

For product data handling, use the localized Privacy Policy and each tool's data-handling badge. For repository security, use [`SECURITY.md`](../../SECURITY.md) and [`docs/security/dependency-audit-policy.md`](../security/dependency-audit-policy.md).
